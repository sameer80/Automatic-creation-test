PROPERTIES WE CAN IDENTIFY (YES)

  Id, Name, Type, Label
  X, Y, Width, Height (position & size from OCR bounding box)
  Placeholder, Required (* marker on label)
  ParentContainer, Confidence, Screenshot source

---

PROPERTIES WE CANNOT IDENTIFY (NO) – Always "Not Available"

  Colors:        Color, BackgroundColor
  Typography:    FontFamily, FontStyle, FontWeight, FontSize,
                 LineHeight, LetterSpacing, TextAlign
  Layout:        LayoutMode, Gap, PaddingTop, PaddingRight,
                 PaddingBottom, PaddingLeft
  Border:        BorderWidth, BorderColor, BorderRadius, BoxShadow

Reason: Screenshot OCR reads text and control regions only. It does not
extract font, color, padding, or border styling from images.

---

PARTIAL (SOMETIMES)

  CurrentValue – only when field has visible text (empty forms = Not Available)
  Enabled      – disabled-state detection is unreliable
  Visible      – defaults to True; hidden controls not detected

RECOMMENDATION

  • Use IDENTIFIED properties for functional test automation and screen matching.
  • Do not assert typography/color/layout from screenshot pipeline alone.
  • For full UI/UX validation (fonts, colors, borders), integrate native
    design-tool FRAME export or a dedicated visual comparison tool.
